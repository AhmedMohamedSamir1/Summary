---- HangFire Types

- Fire-and-Forget (runs once immediately)
	✔ Runs exactly one time
	✔ Immediately (as soon as a worker is free)
	- IBackgroundJobClient.Enqueue<EmailJobService>(x => x.SendDailyReport());
	- 

- Delayed [Schedule] Job ( i.e Runs after 10 minutes: )
	✔ Runs exactly one time
	✔ But in the future
	IBackgroundJobClient.Schedule<EmailJobService>(x => x.SendDailyReport(), TimeSpan.FromMinutes(10));


- Recurring Job (Runs every day at midnight)
	IRecurringJobManager.AddOrUpdate<EmailJobService>( "daily-report", x => x.SendDailyReport(), Cron.Daily);
	IRecurringJobManager.AddOrUpdate<EmailJobService>( "hourly-report", x => x.SendDailyReport(), Cron.Hourly);

	-- registered in Program.cs


- Continuation Job [ Runs after another job finishes ]
	- Runs exactly one time
	- BUT only after another job succeeds

- 
	var jobId = IBackgroundJobClient.Enqueue<EmailJobService>( x => x.SendDailyReport());
	IBackgroundJobClient.ContinueJobWith<EmailJobService>(jobId, x => x.SendDailyReport());

<< schedule inside service >>

 private readonly IBackgroundJobClient _jobs;

 public TagService(IBackgroundJobClient jobs)
 {
   _jobs = jobs;
 }

 public void ScheduleDelete()
 {
    var runAt = DateTime.Now.AddMinutes(10);
    _jobs.Schedule<TagJob>(
     x => x.Delete(1),
     runAt);
 }
